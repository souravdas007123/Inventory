🧾 GSTR-2B Check

You can claim Input Tax Credit (ITC) only for purchase bills that show in your GSTR-2B. Upload the file from the GST portal and this page compares it with your purchases: which bills are missing, and which have a different amount. The file is read and not stored.
How to get the file: GST portal → Returns → GSTR-2B → choose the month → Download (the JSON file). A plain Excel / CSV list with the columns GSTIN, Invoice number, Invoice date, Taxable value, CGST, SGST, IGST also works.
