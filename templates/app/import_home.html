Where to start

  1. Import Suppliers: required before any stock can be entered.
  2. Import Stock Entry (your supplier bills / opening stock). Medicines that are not in Products yet are created from these rows, so you do not need a separate product list first.
  3. (Optional) Import Products to add medicines that have no stock yet, or to fill in MRP, barcode and packs.
  4. (Optional, any time) Customers, Expenses, and Units, Categories, Brands (these are also created automatically).

On every list page (Products, Bills, Purchases...), the ⬇ Excel / CSV button downloads the whole list.
