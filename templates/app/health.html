How the score is worked out

Each part starts at 100 and loses points for every real problem found (the number next to the problem). The total is a weighted average: Data 40%, Safety 25%, Speed 20%, Shop 15%. Speed is how long the main queries take on this server right now. A check that cannot run is never counted as good: it is shown as "?" and left out. The score is measured again every night by the daily task and whenever you press "Measure again".
